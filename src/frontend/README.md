# VidyaMitra Frontend

VidyaMitra is an AI-powered career mentor platform built on the Internet Computer. This frontend application provides resume evaluation, skill gap analysis, mock interviews, personalized learning plans, and progress tracking.

## Prerequisites

- **Node.js**: Version 18 or higher
- **dfx**: Internet Computer SDK ([Install dfx](https://internetcomputer.org/docs/current/developer-docs/setup/install/))
- **Git**: For version control
